# Slack MCP

Reads and posts to Slack. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/@modelcontextprotocol/server-slack

Installs from the Camillia hub as `slack-mcp-461931`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
